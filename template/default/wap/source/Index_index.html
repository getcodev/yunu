关于我们 / ABOUT US

公司总占地50万平方米，拥有世界上最先进的石材加工设备——80台****钻石切机，40台全自动磨台，80台红外线切割机及各式异形工程板加工设备等， 形成了富有规模的大理石大板、工程板、手工工艺加工生产线。****年，公司引进国内外全套先进的岗石生产设备和高新技术，致力研发生产高新产品，满足市场对大理石品种多样化的需求，年生产人造大理石可达1000万平方米。是目前中国最具规模的天然大理石及人造大理石生产基地。【详细介绍】
